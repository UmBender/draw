# draw — Home

A minimal, fast, keyboard-first scratch canvas for competitive programming.
Nothing is saved: draw, think, throw away.

## Principles

1. **Never break during a contest** — few features, few dependencies, boring code.
2. **Fast on weak hardware** — redraw only when something changes.
3. **Keyboard first** — every tool and action has a shortcut.
4. **Shaky-hand friendly** — strokes are smoothed and simplified.
