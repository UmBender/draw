# ADR-T134-1 The automaton wraps the editor behind a routing table

## Context

The 2.0 proposal (§3) wants `step(Machine, Input) -> (Machine, Vec<Effect>)`
over closed sum types. The behaviour today lives in a 10k-line `Editor` that
the fuzz and snapshot tests pin down. Rewriting it in one task would change
behaviour and break those tests; the proposal says the old `Editor` stays as
an adapter until the tests agree.

## Decision

- `draw_core::machine` holds `Input`, `Effect`, `Interaction` (the state the
  user sees: `Idle | Gesture | TextEdit | Palette | Sheet`), `Machine` and
  `step`.
- `Machine` owns an `Editor`. `step` classifies the interaction from the
  editor, looks the `(InteractionKind, InputKind)` cell up in a routing table
  (`Route::Editor` or `Route::Ignore`), and for `Route::Editor` feeds the
  event to `Editor::handle`; the editor's request flags and notice become
  `Effect`s. The table is the only place that says what each state does with
  each input. Later tasks (T135 to T137) move behaviour from the editor into
  the table cell by cell.
- The table is a `match` over `(InteractionKind, InputKind)` with no wildcard
  arm. Cells ignored in T134: `Tick` and `Reply` (nothing consumes them yet).
- The module is registered with one line in `crates/draw-core/src/lib.rs`,
  which the task note does not list: a new module cannot exist without it.
  UNATTENDED CHOICE: the owner should confirm this one-line edit.
- The diagram in `docs/architecture/Control automaton.md` is generated by
  `diagram()` from the table; the test `diagram_matches_the_table` fails when
  the note and the table differ.

## Alternatives considered

- **Rewrite the editor as the machine now** — changes behaviour, breaks
  snapshots and the fuzz suite; too large for one task.
- **Tables as data (`const` array)** — a `match` gives the compiler's
  exhaustiveness check, which is the point of AC-2.

## Consequences

Totality is checked by the compiler from day one, behaviour is unchanged,
and the table grows as T135 to T137 move logic. `Editor` and `Machine`
must agree, tested by `machine_and_editor_agree`.

## Rollback plan

Delete `crates/draw-core/src/machine/` and the `pub mod machine;` line; the
editor is untouched.
