# T127 2.0 audit and baseline

## Goal

Measure the app as it is and turn the 2.0 proposal into ADRs, so every later task starts from numbers and not from memory.

## Known facts (2026-11-12)

- [[2.0 Architecture proposal]] is `proposed`; the frame-time numbers it quotes are from before [[T26 Pan and zoom without re-rendering]] and must be re-measured.
- The vendored miniquad is 26.7k lines; 19 files of `src/shell` and `src/core` use macroquad.
- `src/core/editor.rs` has 10.5k lines and `src/core/tex.rs` 11k.

## Spec

This task is docs and scripts: no Rust code is added, so the "tests" are
the audit scripts and a check that each report table was produced by one.

- AC-1 is met by `scripts/audit/*.sh` (one script per table: `sizes`,
  `coupling`, `tests`, `coverage`, `unsafe-dyn`, `mq-calls`, `frames`) and
  by `docs/architecture/2.0 baseline.md`, which names the script of each
  table. Frame times that cannot be measured here are written "not measured
  on the i5-8250U"; no number is invented.
- AC-2 is met by `ADR-T127-1` to `ADR-T127-5`, all `proposed`, each quoting
  the owner's decisions of 2026-11-12 from the proposal.
- AC-3 is met by a section "Child tasks checked" in the report.

- **AC-1** — A baseline report in `docs/architecture/2.0 baseline.md`: frame times of the ADR-T24-5 scene on the target (`DRAW_FRAME_TIMES=1`, i5-8250U), module sizes and coupling (who imports whom), test counts per module, coverage per module (`cargo llvm-cov`, run by hand), the count of `dyn`, `Box<dyn` and `unsafe` in `src` and in `vendor/miniquad`, the macroquad and miniquad calls draw really uses.
  The report's tables are produced by scripts kept in `scripts/audit/` so the baseline can be repeated.
- **AC-2** — Five ADRs are written and `proposed`: `ADR-T127-1` the 2.0 architecture (workspace, automaton, static dispatch); `ADR-T127-2` the `unsafe` policy, amending ADR-0014; `ADR-T127-3` the dependency list, amending ADR-0014; `ADR-T127-4` an own backend replaces the patched miniquad and macroquad; `ADR-T127-5` OpenGL ES 3.0 first, Vulkan optional.
  The decisions of the owner of 2026-11-12 are quoted in each one.
- **AC-3** — The child tasks below are checked against the baseline: any task whose premise the numbers contradict is rewritten before it starts.
